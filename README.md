# FBI-NEXUS

**Network for Enforcement, X-Intelligence, & Unified Security**

نظام إدارة قضايا فيدرالي كامل يعمل داخل المتصفح (بيئة GTA RP / مكتب لوس سانتوس الميداني)، بواجهة عربية RTL وهوية مؤسسية، ويخزّن كل البيانات محليًا على جهاز المستخدم — لا خادم ولا قاعدة بيانات خارجية.

---

## المزايا

- **الشبكات والهياكل التنظيمية**: إضافة شبكات/عصابات بمواقعها وأعضائها بلا حد.
- **المطلوبون والسجلات**: صور، أدلة، اتهامات، مكافآت، ربط بالشبكات، ونشرة مطلوب PDF.
- **خريطة تفاعلية**: خريطتا لوس سانتوس وسان أندرياس مع حفظ إحداثيات المواقع والعلامات.
- **المذكرات والطلبات القضائية**: توقيع وختم صاحب الحساب، مرفقات PDF/صور، وطباعة جاهزة للاعتماد.
- **البرقيات والتعميمات**: أولويات (عادي/هام/عاجل/سري للغاية) وطباعة رسمية.
- **ملفات القضايا**: مراحل، خط زمني، أدلة، إحالة إلى وزارة العدل، واعتماد/رفض.
- **الأدلة الجنائية**: ترقيم تلقائي، سلسلة حفظ، مختبر ونتائج، ملصقات باركود، وتقارير PDF متعددة الصفحات.
- **بوابة وزارة العدل**: حسابات مخصّصة ترى المذكرات والقضايا المحالة فقط، تعتمد أو ترفض أو ترسل ملاحظات (تعديل/ملفات ناقصة).
- **حسابات وصلاحيات**: كلمات مرور مشفّرة (SHA-256 + Salt)، جلسة محلية، قفل تلقائي بعد 15 دقيقة.
- **سجل تدقيق** لكل حركة، وتصدير/استيراد الأرشيف كاملًا (JSON).

## التشغيل

> النظام ملفات ثابتة داخل `public/`. لا يحتاج بناءً ولا قاعدة بيانات.

### 1) GitHub Pages (الأسهل — بدون تثبيت أي شيء)

1. ارفع المستودع إلى GitHub.
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. الوركفلو الموجود في `.github/workflows/deploy-pages.yml` سينشر مجلد `public` تلقائيًا عند كل Push إلى `main`.
4. الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### 2) محليًا على ويندوز (بدون Node)

- شغّل `start.bat` — يفتح المتصفح على `http://localhost:3000`.
- أو يدويًا:
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1 -Port 3000
  ```

### 3) محليًا باستخدام Node.js

```bash
npm install
npm start
# http://localhost:3000
```

### 4) أي خادم ملفات ثابت آخر

وجّه الجذر إلى مجلد `public`، مثلًا:
```bash
npx serve public
```

> **مهم:** لا تفتح `public/index.html` مباشرة بنقر مزدوج (`file://`). التخزين المحلي (IndexedDB) وتشفير كلمات المرور (WebCrypto) يحتاجان خادمًا عبر `http://localhost` أو HTTPS.

## الحسابات

- تُنشأ الحسابات تلقائيًا في أول تشغيل على الجهاز.
- **A-140** هو الحساب المسؤول كامل الصلاحيات، ومن **الإعدادات** يضيف بقية الحسابات (محققين أو حسابات وزارة العدل).
- كل حساب له اسم معروض ورتبة (من قائمة رتب FBI) وتوقيع وختم خاص.
- الحسابات والبيانات تُحفظ في متصفح الجهاز (`localStorage` + `IndexedDB`) ولا تُرسل إلى أي خادم.

## هيكل المشروع

```
public/
  index.html          # واجهة النظام
  css/main.css        # الثيم والأنماط والطباعة A4
  js/db.js            # FileStore — تخزين الصور والملفات في IndexedDB
  js/map.js           # الخريطة التفاعلية
  js/auth.js          # الحسابات والصلاحيات والجلسة
  js/core.js          # الحالة، الراوتر، النماذج، لوحة القيادة
  js/ops.js           # المذكرات، البرقيات، القضايا، الأدلة، التقارير، الإعدادات
  assets/             # شعار FBI وخريطتا لوس سانتوس وسان أندرياس
tools/
  serve.ps1           # خادم ملفات محلي (PowerShell)
  make-map.ps1        # أدوات تجهيز الخرائط
server.js             # خادم Express اختياري
```

## الطباعة و PDF

كل مستند (مذكرة، برقية، نشرة مطلوب، تقرير أدلة، ملف قضية) يُطبع من المتصفح عبر **Ctrl+P → حفظ كـ PDF** بمقاس **A4**. لا حاجة لأي مكتبة PDF خارجية.

## ملاحظات

- البيانات محلية لكل متصفح/جهاز؛ لعمل نسخة احتياطية استخدم **الإعدادات → تصدير الأرشيف الكامل**.
- مسح بيانات المتصفح يحذف الأرشيف — احتفظ بنسخة JSON خارج الجهاز.
- المستودع لا يحتوي أي مفاتيح أو أسرار.
